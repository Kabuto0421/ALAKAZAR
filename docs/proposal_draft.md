## 2. コンセプトと売り

1. **武器 = 移動の仕方。** 武器ごとに「どの方向へ動けるか」と「どこを攻撃できるか」が違います。将棋の駒のように、持ち替えで動き方が変わります。前進剣、桂馬剣、八方桂剣、飛車槍、角剣など、将棋を思わせる47種類があります。
2. **妖精 = スキル。** 24種類の妖精が、召喚、設置（大砲・壁・猫のフィールド）、範囲攻撃（隕石・氷結）、時間停止などで戦況を変えます。クラスアップで強化できます。
3. **「読める」戦闘。** 敵の行動は、前もって予告として画面に出ます。「！」の付いた敵は、次のターンに殴ってきます。運ではなく、読んで動く戦闘です。
4. **組み合わせの爆発。** 大砲の連鎖（CHAIN）、隕石の雨、魔法陣で囲んで99ダメージ、守護神が妖精を呼び戻す、など、ビルドで派手な場面が生まれます。
5. **作り込まれたボス戦。** ボス3体はそれぞれルールが違います（後述）。

## 3. ゲームの流れ

- 行動は、1ターンに**AP2**。移動1AP・攻撃1AP・妖精の召喚（ほとんど1AP）。武器の持ち替えは0AP。
- 主人公のHPは5。敵にもAP（行動回数）があり、同じ距離でもAP1の敵とAP2の敵で動きが変わります。
- **1ランの構成（全13戦）**：序盤3戦（4×4、5×5、6×6）→ ボス1 → 中盤3戦 → ボス2 → 終盤4戦 → 最終ボス。
- 戦闘のあとは、報酬として、武器または妖精のカードを選びます（レアリティは4段階）。
- キャンプでは、休憩（HP回復）、武器の強化、妖精のクラスアップができます。
- 盤面は4×4から10×10まで、戦闘ごとに大きくなります。

## 5. 敵とボス

**兵士（16種）**：歩兵、重装兵、跳躍騎兵、馬、投げ槍兵、弓兵、盾兵、解析兵（殴られた武器を覚えて無効化する）、金将兵、銀将兵、執行兵、地雷兵、バッテン兵（斜めにだけ動く）、道化兵（3ターン眠ってから覚醒してAP3）、竜装兵（左3マスを砲撃）、など。

**ボス**
- **ボス1**：馬3体、または突進くん＋移動監獄（2×2）。
- **ボス2**：ロトリック（スロットの出目で行動が変わる）、または嵐鮫（潜って影から再出現する）。
- **最終ボス：監獄の王**（10×10の盤面）：要塞監獄を壊すまで無敵になる怒り状態があり、倒すと実績が解除される。

## 9. 素材・権利・生成AIの利用

- **コード**：GDScript。実装の大部分に、AIコーディング支援ツール（Claude Code）を使用。設計と仕様の決定、テスト、調整は作者が行っている。
- **絵（キャラクター、背景、UI素材、タイトル画面、アイコン）**：画像生成AI「GPT-Image-2.5」で生成した素材を使用。生成後に、ゲーム用の加工（切り抜き、ドット絵向けの調整、合成）を行っている。
- **BGM**：作者の指示でAIが書いた作曲・合成スクリプト（`tools/generate_bgm.py`）により、プログラムで合成。
- **効果音**：大半は、スクリプト（`tools/generate_sfx.py`）で合成したもの。3点はCC0素材（Juhani Junkala氏）で、作者のクレジットを `assets/audio/sfx/CREDITS.md` に記載。一部は自作の録音。
- **フォント**：DotGothic16、VT323（SIL OFL）。
- 素材の由来一覧：`ASSET_PROVENANCE.md`
