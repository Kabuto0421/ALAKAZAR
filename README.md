# ALAKAZAR

武器ごとに異なる移動・攻撃範囲と妖精のスキルを組み合わせて戦う、Godot製のターン制タクティクスです。初期ビルドを選び、4×4・5×5・6×6の3戦を攻略しながら報酬で構成を更新するプロトタイプです。

## 起動

動作確認環境は **Godot 4.7.2（GDScript／GL Compatibility）** です。Godotで `project.godot` をインポートし、素材の読み込み後に **F5** で実行してください。**タイトル画面**（`title.tscn`）から始まり、「GAME START」で初期ビルド選択へ進みます（敵に倒されたときは、結果画面の「タイトルへ戻る」でこの画面に戻ります）。

### タイトル画面

- 素材は `assets/title/`（1920×1080の5枚のレイヤー。背景・主人公と妖精たち・監獄軍勢と監獄の王・ロゴ・メニュー枠。`layout.json` に元の座標）。1728幅の画面に中央合わせで置き（左右96pxずつ切れる）、両軍だけ30pxずつ内側に寄せて端のキャラが切れないようにしています（`scripts/title/title_screen.gd`）。
- 曲は `title_theme.ogg`：ケルト風の戦いの曲。ファンファーレ（Dドリアン・100BPM・5小節。バグパイプのドローンとバウロン／ティンパニのロールから、戦いのバグパイプが装飾音つきで呼びかけ、大きなDの和音へ）のあと、116BPM・23小節の行進曲（41.85〜43.03秒の約1.18秒はカット）が次の3部でループします：**①ケルト（12.0秒〜、Am–F–G–C…）**＝ホイッスルとハープの優しい旋律から始まり、17.1秒でパイプ・金管・戦太鼓が入って戦闘らしくなる（その直前の半小節で、ライザー・音量が0から上がるスネアロール・忍び込むベースと戦太鼓・駆け上がるアルペジオで助走をつけ、ホイッスルの最後の音D6にパイプが同じ音で着地する） → **②完全なサイバー（約26.5秒〜41.85秒、ケルト風の音は一切なし。音量はほかの部分と同じ＝RMS約0.19）**＝直前に逆回転のクラッシュとライザーで盛り上げて、サブベースのインパクトとともにドロップ。Gを経由してEマイナーへ転調し、EDMの定番進行 Em–C–G–B → Em → B → Em（i–VI–III–V–i–V–i）。4小節目（ブレイク）の終わりに導音D♯6へ上がり、5小節目（約34.8秒）の頭のE6へ解決して山場。**36.8〜41秒（6〜7小節目）はメインメロディが全体を完結へ向かわせる部分**で、Bの上でフックの3+3+2が導音D♯6を回り、Emの上で主音に着地して**E6で終わる**（キックは1拍ずつ減り、最後の4ステップはドラムが止まってE6だけが響く）。続いて**アウトロ（41.0〜41.85秒、約0.85秒）**＝Emの上でパッド・アルペジオ・サブだけになり、落ちていくノイズとともに音量が約0.10から約0.07へ下がっていく所で、**41.85秒に急に次の部分の頭へ切り替わる**。元のデータにはこの先にアウトロの残り（無音近くまで下がる所）と約1秒の盛り上げ（ライザー・スイープ・スネアロール・逆回転クラッシュ）がありましたが、**41.85秒から次の部分の最初の一撃（43.03秒）の直前までの約1.18秒は丸ごとカットしてある**（`generate_bgm.py` の `joined.cut`）。カットの終わりを、盛り上げのノイズが途中で始まる所ではなく、最初の一撃（クラッシュとキック）の頭ちょうどに合わせてあるので、つなぎ目の直後は一撃そのものから始まり、突然ノイズが入るプチ音が出ない。つなぎ目の手前だけ5msのコサインでフェードアウトする → **③サイバー＋ケルト（41.85秒〜、Em–C–G–D–Em–C–D–G）**＝2つが合わさって始まり（クラッシュとキックと着地のヒット）、1小節ごとに楽器が減って静まっていき（最後はホイッスルとハープだけ）、最後のGからAmへ①の頭に戻ります。ファンファーレは最初の1回だけです（`.import` の `loop_offset`）。
- **妖精は使ったものだけが色づきます**。タイトル絵の主人公側は、1体ずつの画像（`assets/title/units/` と配置の `assets/title/units.json`、`scripts/title/title_roster.gd`）で組んであります。戦闘で**実際に使った**妖精（`BattleView._commit_item`）は `scripts/fairy_book.gd` が妖精のIDで記録し（`user://fairy_book.cfg`）、まだ使っていない妖精は暗いシルエットで同じ位置に立っています。初めて使った妖精は、次にタイトルを開いたときメニューが出た直後に、シルエットからぽんと飛び出します（演出の対象は `unseen()` で管理）。主人公は常に色つきで、聖精霊を使うと聖騎士も一緒に解放されます。
- **体験版の「起動のたびに初期化」は切ってあります**（`DEMO_RESET = false`。妖精の解放記録と実績は残ります。もう一度初期化したくなったら `true` に。妖精の解放記録と、これから作る実績。`scripts/launch_reset.gd`）。タイトルを最初に開いたときに1回だけ消し、戦闘で負けてタイトルへ戻ったときは消しません。製品版で記録を残したくなったら `DEMO_RESET` を `false` にします。テストと撮影ツールは記録を止めているので、手元のデータを消しません。
- **絵のない妖精も自動で並びます**（`scripts/title/title_extras.gd`）。`TitleRoster.ITEM_OF` にない妖精（今は時の妖精）は、妖精の列の上の空き（`AREA`）に左から順に置かれ、同じように使うまでシルエットです。絵や画像を描き足したら `units.json` に足し、`ITEM_OF` に対応を書くと自動枠から外れます。空きは20体分で、絵のピクセルとロゴに重ならないことはテストで確かめています。
- 画面は曲に合わせて現れます：ティンパニのロールで暗転から明け、金管の第一声で両軍が左右から入りロゴが着地（白く光る）、続いてメニューが出て、ファンファーレ最後の和音で画面が光って揺れます。森には蛍、監獄都市には雨が動きます。何かキーかクリックで演出を飛ばせます。
- **曲に合わせて絵が動きます**（ファンファーレのあとも。`scripts/title/title_screen.gd`）。曲のどこでどの音が鳴るかを書いた**キューシート** `assets/audio/bgm/title_theme.cues.json` を `tools/generate_bgm.py` が音を置くたびに記録して書き出し（キック・戦太鼓・クラップ・大きな一撃とその種類・メロディの音程と長さ・ハープ・曲の部分・盛り上がりの強さ。41.85〜43.03秒のカットも反映済み）、ゲームは `scripts/title/title_sync.gd` で読みます。曲の位置はオーディオの再生位置（ミックス間を補間し、出力遅延を引く）から取るので、処理落ちしてもループしてもずれません（鳴っていない時だけ画面の時計）。絵の状態はすべて「最後のキック／一撃からの経過時間」の関数なので、フレームレートに依らず曲と合います。
  - **色**：曲の部分ごとに森（左）と都市（右）を別々に色付け（`title_grade.gdshader`）。ファンファーレは素の色 → ケルト（月夜の森、都市は暗く冷たい）→ 戦太鼓が入る17.17秒から都市が赤く燃える → 26.48秒で完全なサイバー（彩度を落とした青緑、走査線、デジタルレイン）→ ビルドアップ、山場、完結、アウトロ（暗く彩度が落ちる）→ 41.85秒の融合（森は鮮やかな緑、都市はシアン、雨は両側に）。切り替えは部分ごとの秒数でなめらかに。ロゴの背後は両側の平均で色付けするので、左右で明るさが変わらない。
  - **キック**：ロゴが膨らみ、メニュー枠が光り、妖精の列が波打って跳ね、ほんの少し画面が明るくなる。**戦太鼓**：監獄軍の赤い灯（目やランプ）が光ってにじみ、軍が半歩出る。**サイバーのキック**：軍のシアンの灯が光る（`title_layer.gdshader`）。
  - **大きな一撃**（9.6秒の和音、17.17、26.48、34.76、41.85秒）：画面が一撃ごとの色でフラッシュし（白・赤・シアン・白・金）、揺れ、色ずれ（色収差）と走査線のずれ（グリッチ。サイバーの一撃で特に強い）が走り、空から二つの軍の境目へ稲妻が落ちて衝撃のリングが地面を走り、ロゴが光って光の筋が横切る。
  - **メロディの音**：音程に応じてロゴの8文字（A L A K A Z A R）のどれかが金色に光る（低い音は左の文字、高い音は右の文字。上がる旋律ならロゴを左から右へ光が走る。`title_logo.gdshader`）。ケルトの音は蛍が一匹ふくらんで光の粒を出し、ハープは蛍がまたたく。サイバーのリードの音は地面から火花が飛び（軍の前を飛ぶ）、融合のメロディは森で金、都市でシアンの火花。
  - **おまけ**：ビルドアップ（32.69秒〜）はカメラが少しずつ寄っていき（最大7%）、山場の一撃で戻る。終盤（約37.8秒〜アウトロ）は黒いレターボックスが閉じていき、融合の一撃で開く。サイバーでは雨が縦に落ちるデジタルレイン（青緑の四角の列）になり、融合では森側にも降る。
  - 曲を作り直したら**キューシートも作り直す**（`python3 tools/generate_bgm.py title_theme.cues.json`。`title_theme.ogg` は手でカットした版なので触らない）。長さが合わないとテストが落ちます。タイトル画面の `override_time`（0以上）で曲の位置を手で指定でき、キャプチャとテストはこれで任意の瞬間を再現します。
- メニューは「GAME START」「実績」の2つを大きな文字（56px）で表示。選択中は金色・左に「▶」・金色の光、そのほかはクリーム色。↑↓（W/S）で選び Enter／Space／Z かクリックで決定。GAME STARTで暗転して `main.tscn`（初期ビルド選択）へ。
- **実績**（`scripts/title/achievements.gd`）。上から順に、①**妖精マスター**（妖精全員を使う。実績ページに「使った妖精 n / 全体」を出す）、②**ALAKAZAR's KING**（監獄の王を倒す＝最終戦に勝つ）、③**天の守護神、ここにあり。**（守護神の妖精が妖精を1体以上呼ぶ。アイコンは守護神を中心に、呼び戻される妖精＝どんぐり・一匹狼・聖精霊・隠密）、④**Y O U　 D I E D**（暴食妖精にプレイヤーが喰われる。題名は赤文字、`title_color`）、⑤**戦場の庭師**（設置系の妖精を、残っているうちに3体以上置く＝5ターン以内に3回。`BattleModel.PLACED_FAIRIES` はカードの「設置」ラベルと同じ一覧で、テストで一致を確かめます）、⑥**ばよえ〜ん！**（設置妖精たちを連携させて、1ターンに5CHAIN以上を起こす）、⑦**え、これできるんだ...**（魔弾・風斧など攻撃系の妖精で設置系を起動する。大砲どうしの連鎖や武器での攻撃は数えない）、⑧**魔法陣最高！魔法陣最高！**（魔法陣武器で魔法陣を完成させる）、⑨**これは一体、どうなっちゃうんだ〜！？**（隕石妖精を3回クラスアップ。キャンプで1回ずつなので、4回あるキャンプのうち3回を隕石に使う）、⑩**ザ・ワールド**（時を止めてる状態で試合を終える）。**ALAKAZAR's KING を解除すると、タイトル画面の黒い王の影が、本来の青い色で玉座に座る姿（待機アニメの1コマ目）に変わります**（`assets/title/layer_20_enemies_fallen.png`、`tools/make_fallen_king.py` で敵レイヤーから王だけを消して作ります）。アイコンは `tools/make_achievement_icons.py` で作り、`assets/achievements/` にあります。未解除のうちはアイコンが「？」、名前が「？？？」（説明文は出したまま。Y O U　 D I E D だけは赤い枠・赤文字のまま）で、解除すると本物に変わります。解除すると画面上部に「実績解除！」のバナー（`achievement_toast.gd`、複数同時なら順番に）が出ます。判定は戦闘のたびに `BattleModel.stats`（その戦闘の最大CHAIN・設置したターン・守護神が呼んだ数・暴食に喰われたか・攻撃系が設置を起動したか・完成させた魔法陣）を `Achievements.check(model)` が読んで行い、戦闘画面は操作のたびに、キャンプなどの間は `RunView._render` で呼びます。`tests/test_run.gd` の `_achievement_scenarios` が、実績ごとに本物のモデルで条件を起こし、満たさない場合に出ないことも確かめます。**実績を足すには** `DEFINITIONS` に `{id, title, description, icon}`（任意で `hidden`、`title_color`、進捗を出すなら `progress()` と `progress_label`）を足し、`check()` に条件を足します。体験版は起動のたびに初期化します（下の `launch_reset.gd`）。

```sh
godot --editor --path .
```

## 探索の流れ

**戦闘画面の「タイトルへ」ボタン**（右上、遊び方の隣）：1回押すと「本当に戻る？」に変わり、3秒以内にもう一度押すとタイトルへ戻ります（途中の記録は残りません）。聖精霊の図は壊れた後に出る聖騎士（クラスアップ後は壊れた2×2の4マスから4体）の「HP2・AP2」と四方向の動ける範囲を、移動監獄の説明は出てくる執行兵の絵・HP2・AP2・上下左右に1マスずつ動くことを示します。

**遊び方（ゲーム内）**：画面右上の「遊び方 [H]」か H キーで、8ページの説明（基本・AP・武器・特殊効果・妖精・設置系の妖精・敵にもAPがある・危険を読む）を開けます。各ページはルールを2行で書き、実際のゲーム画面のスクショで見せます。スクショはパラパラ漫画のようにループ表示し（APを使い切る→敵のターン→またあなたのターン、など）、「移動 −1 AP」「持ち替え 0 AP」などのタグでAPの使い方を毎回見せます。スクショは `assets/help/` にあり、画面のデザインが変わったら `xvfb-run godot --rendering-driver opengl3 --path . --script res://tools/capture_help.gd` で撮り直せます（ゲーム起動時には撮影しません）。ゲームを起動して最初の戦闘では自動で1回だけ開きます（どこにも保存しないので、起動するたびに1回出ます）。

**戦闘1（4×4）→ 戦闘2（5×5）→ 戦闘3（6×6）→ キャンプ → ボス戦（7×7）** の順に進みます。

1. 右隣だけに動ける「前進剣」と左隣だけに動ける「後退剣」に、3本目を追加します。候補は、序盤用の武器のうち上下両方へ行ける序盤用の武器12種から3つ抽選されます。妖精選択から「← 武器選択」で戻っても、候補は変わりません。
2. 武器を選ぶと、魔弾精霊・隠密妖精・どんぐり妖精から1つを選ぶ画面に進みます。
3. 戦闘は**プレイヤーの手番から**始まります。プレイヤーは左側・右向き、敵は左向きで固定です。
4. 全滅させると妖精の使用回数が回復し、武器3候補・妖精2候補から報酬を1つ選びます（何も取らずに進むこともできますが、おまけはありません）。
5. 武器・妖精はそれぞれ最大3枠。満杯なら手放す装備を選んで交換します。交換を取り消して同じ報酬候補に戻ることや、報酬を取らずに進むこともできます。
6. 戦闘3の報酬の後は**キャンプ**です。次のどれか1つを選びます。
   - **休む**：HP+2（最大5）
   - **鍛える**：所持している武器を1本選び、攻撃力+1。1本につき1回まで。入れ替え武器（入替の杖・王将の杖）はダメージを与えないので、代わりに**毎ターン最初の入れ替えが0 AP**になります（2回目からは1 AP）
   - **妖精のクラスアップ**：所持している妖精を1体選び、効果を強化。さらに、設置・使い切りの妖精は**毎戦闘の使用回数が1増える（消費APはそのまま）**。召喚の妖精（どんぐり・暴食・守護神）と槍砲精霊・蓄電の妖精は**消費APが1減り（0 AP）、使用回数も1増える**。例外として、一匹狼と影縫いは**0 APになる（回数は増えない）**、聖精霊は**聖騎士が4体になるだけ**、隕石は**隕石の数が増えるだけ**、隠密は**刺しても消えなくなるだけ**です。1体につき1回まで

   クラスアップ・鍛える画面のカードでは、強化で変わる部分（説明文の違う箇所、AP・使用回数、攻撃力）を**緑色**で表示します。強化した武器・妖精は、名前に黄色い「+」が付き、アイコンや範囲図の角に黄色い四角の「+」バッジが付きます（盤面に置いた妖精にも付きます）。クラスアップした妖精を報酬の交換で手放すと、強化も失われます。

   | 妖精 | クラスアップ後 |
   |---|---|
   | 魔弾精霊+ | 選んだ向きとその反対向きの両方に撃つ |
   | 斬撃精霊+ | 向きを選び、置いたマスの上下2マス（素の範囲）と3マス幅×5マスの斬撃を同時に飛ばす |
   | 隠密妖精+ | 刺しても消えず、5ターン残る（1ターンに1回刺す） |
   | どんぐり妖精+ | HP2になり、斜めの敵も攻撃する |
   | ワープ妖精+ | 毎戦闘2回使える（もともと0 AP） |
   | 壁精霊+ | 向きを選び、その向きへ一直線に3マスの壁を置く（ふさがったマスの手前まで） |
   | 重力妖精+ | もっと遠く（周囲3マス）から引き寄せ、2マス弾く（0 APのまま、毎戦闘2回） |
   | 時の妖精+ | 0 APで使える（回数は1回のまま） |
   | 加護の妖精+ | 加護の地が5×5に広がり、中でターンを終えるとHPが1回復する |
   | 花火妖精+ | 爆発が自分と味方を巻き込まない |
   | 槍砲精霊+ | 0 APで置ける・毎戦闘2回（1発のまま） |
   | 蓄電の妖精+ | 0 APで置ける・毎戦闘2回 |
   | 影縫い精霊+ | 置くのも入れ替わりも0 AP（通常はどちらも1 AP） |
   | 一匹狼の妖精+ | 0 APで呼べる |
   | 風斧精霊+ | 毎戦闘2回使える（1 APのまま） |
   | 聖精霊+ | 壊れると聖騎士が4体出る（2×2の空いている全マスから）。1 APのまま、回数も増えない |
7. キャンプの後は**ボス戦**：7×7の盤で、HP2の馬3体と戦います。倒すと遠征達成です。

**HPは戦闘をまたいで持ち越し、勝つたびに1回復します**（難易度を上げると回復なし。`run_model.gd` の `difficulty` を1以上にすると無効。最大5。戦闘中の `R` では、その戦闘を始めたときのHPに戻ります）。妖精の使用回数は戦闘ごとに回復し、獲得した装備と鍛えた攻撃力は引き継ぎます。

### 序盤の編成

**レアリティ**：報酬のカードは枠の素材と右上のバッジでレアリティを示します。枠は**コモン＝木**（木目と節、鉄の釘）、**アンコモン＝翡翠**（乳白色の雲が混じる緑の石）、**レア＝ラピスラズリ**（深い青に金色の黄鉄鉱の粒、金の鋲）、**激レア＝黄金**（磨かれた金、赤い宝石、枠をぐるりと走る光の筋と光る外周）。素材は `tools/generate_frames.py` で作るドット絵のタイルで、縁に光と影を付けています。カードにカーソルを乗せると枠が明るくなります。同じ素材の枠（少し細め）は、戦闘画面の武器欄・妖精欄と、報酬画面下の所持武器・所持妖精の欄にも付きます。報酬画面の「今の構成で進む」ボタンは、水色のシンプルな枠で目立たせています（文字は白）（装備中の武器・選択中の妖精は枠が明るくなり、内側にその色の線）。文字は枠の内側に収まるよう、長い要約は一段小さい文字で2行に折り返します（1文字だけ次の行に残らないよう言葉の切れ目で折る）。**説明の文字色**：費用（AP・回数）・要約・注記・「選ぶ →」・戦闘中の補足など、ただの情報の文字は、紫や灰色をやめてすべてレアのラベルと同じ水色で統一しています（強い攻撃の金・魔法陣のピンク・クラスアップの緑・使用済みの暗い灰色は意味がある色なので残しています）。**コモン**（銅）・**アンコモン**（緑：3マス武器・中盤武器・上下剣・前斜剣・重力／影縫い／一匹狼／氷結／加護の妖精）・**レア**（青：魔法陣武器・ハンマー・十字剣・交差剣・金将剣・銀将剣・風斧精霊・奈落の精霊・ワープ妖精）・**激レア**（金・光る枠：飛車槍・角剣・八方桂剣・十字槌・暴食妖精・守護神の妖精・聖精霊・時の妖精・隕石妖精）。**ハンマー系の武器（木槌・ハンマー・十字槌）は、本来の位置より一段上のレアリティ**です（木槌＝アンコモン、ハンマー＝レア、十字槌＝激レア）。武器もレアリティを先に抽選します（下の「序盤は1マスずつ…」の段落）。妖精のカードは、まずその報酬のレアリティの確率（`run_model.gd` の `FAIRY_TIER_ODDS`）でレアリティを決め、そのレアリティの妖精から1体を選びます。どの妖精も最初の報酬から出る可能性があり、進むほどレアが出やすくなります（1枚あたり：戦闘1・2の後 コモン80%・アンコモン15%・レア4%・激レア1% → 1体目のボスの後 激レア5% → 中盤3の後から終盤まで コモン25%・アンコモン30%・レア35%・激レア10%）。報酬カードの小さな盤面は、その武器で動けるマスをそのまま表示します。ハンマー系（ハンマー・木槌・十字槌）は、右のマスを叩いた時に響くマスをオレンジの斜線で重ねて表示し、図の主人公もハンマーを持った立ち絵にします（報酬カード・所持武器・戦闘中の武器欄と範囲図）。武器カードの説明文は図で分かる範囲の説明を省き、特殊効果（ハンマーの響き・溜め・引き寄せ・弓は動けない等）だけを載せます。カード左上の「武器」「妖精」の見出しは出さず、「クラスアップ後」「魔法陣武器」のような特別な見出しの時だけ表示します。妖精のカードは、戦闘中に妖精を選んだ時と同じ**動く例の図**（マス目の上で、妖精の絵がマスいっぱいに入り、右を向いた主人公・敵・矢印・ダメージの数字で動きを見せる）を大きく載せ、文字は一行の要約だけにしています。右上のレアリティのバッジの左には**召喚**（HPを持つ味方）・**設置・5ターン**（5ターンで消える）・**使い切り**のラベル（小さなラベルも本文と同じドット文字 DotGothic16 を、くっきり表示される16pxで表示）、大砲系（槍砲・風見砲・花火・蓄電）には共通の「誘爆：他の大砲・魔弾でも発動」の一行、召喚妖精はHPとAPを主人公と同じハートと金の四角で表示。守護神の妖精は呼び直す妖精（隠密・どんぐり・一匹狼・聖精霊・暴食）をアイコンと名前で示します。影縫い・一匹狼・奈落・重力・隕石の図は「例：銀将剣」として、銀将剣の届くマスを白枠で示したうえで、届かないマス／届くマスでの違いを段階的に見せます（一匹狼は「単独で2」「隣に仲間で1」「届くマスですねる」、暴食は「1×1の敵を喰う」「2×2は喰えない」「主人公も喰う」）。奈落の精霊の図は、自分のマスを押すと精霊が現れ（その後は主人公のマスの角で光り続ける）、奈落が広がり（敵や障害物のマスは奈落にならない）、敵が奈落に入れず、押し込むと撃破、最後に主人公が動くと届く範囲が変わって奈落も変わる（変わるマスが点滅）所までを4段階で見せます。どんぐり・聖精霊・暴食・守護神の図には、その妖精が動ける・攻撃できるマスを緑の点線枠で示します。分類ラベルはレアリティのバッジの左に並べ、名前の下に「置く場所：武器の範囲／届かない所／どこでも／自分のマス」を表示します。報酬画面で武器と妖精が並ぶ時は、図の大きい妖精カードを広く、武器カードを細く（7割）して、妖精の図をカードの端近くまで大きく描きます。魔法陣などエンチャントの効果の文字は、他で使わないピンク色で表示します。分かりにくい妖精（奈落・一匹狼・影縫い・暴食・隕石・守護神・加護・蓄電）は要約の代わりに少し詳しい一文を載せます。クラスアップのカードは、クラスアップで増える効果だけを緑の短い一行で表示します。

**魔法陣武器**（レア）：報酬の武器にまれに「魔法陣」の付いたものが出ます（報酬1回あたり3%、`CIRCLE_CHANCE`。付くのは動けるマスだけのシンプルな武器だけで、効果のある武器・弓・入れ替え武器には付きません。飛車槍・角剣は常に魔法陣付き）。魔法陣武器は攻撃できず（敵や大砲は選べない）、移動だけができます。移動すると、立っていたマスと着地したマスが白くなり、戦闘の間ずっと残ります。白いマス（斜めにつながっていてもよい）で囲碁のように囲むと、囲った内側と白線の上にいる敵すべてに**99ダメージ**。盤の端は壁になりません。使った白線は消えます。移動先にカーソルを乗せると、そこで囲める範囲が金色に光ります。ダメージ床（ロトリックの出目4）は白いマスの上に重ねて表示されます。

影縫い精霊・奈落の精霊は、武器が届かないマスに置く妖精です（一匹狼は攻撃範囲内に置きます）。八方桂剣・金将剣などの広い武器を持つほど置ける場所が減るので、どちらを取るかの駆け引きになります。

風斧精霊（レア）と聖精霊・時の妖精（激レア）も、ほかの妖精と同じ抽選で出ます。ボス（1体目・ロトリック）を倒した直後の報酬だけは**ボス撃破ボーナス**で、妖精カードのレアが+5%、激レアが+2%されます（その分コモンが減る。`BOSS_FAIRY_BONUS`）。報酬画面の見出しの横に「ボーナス：レア・激レアの妖精が出やすい」と出ます。

**突進くん**（HP3・AP1・2×2）：青・左向きで登場し、少し間をおいて、プレイヤーの最初のターンの前に赤く構えます（ボス演出。構えた姿はしゃがんで低くなるので、2×2だと分かるよう2×2いっぱいの大きさで描きます）。以後は毎ターン、構えた向きへ飛車のように突進（1 AP）し、突進後すぐにプレイヤーへ構え直します。2マス幅の突進路は赤い斜線で表示されます。突進路にいると1ダメージを受け、突進くんと一緒に壁まで押し込まれます。避けた場合は、プレイヤーと同じ軸に並ぶところまで進んで止まり、そちらへ構え直します。突進路にある壁精霊・大砲（全種）・隠密妖精・影縫い精霊の影・味方・障害物は粉砕し、その手前で止まります（赤い斜線の突進路もそこで途切れます）。盤面の端では止まります。他の敵は、プレイヤーが突進路にいるときはプレイヤーごとまとめて押し出し（押された敵にダメージはなし）、プレイヤーが避けているときは壊さずその手前で止まります。

**ノックバック武器**
この武器の攻撃は**ダメージを与えない**が、敵を攻撃した向き（自分→敵）の**一番奥まで**ノックバックさせます（盤の端・壁精霊・障害物・大砲・味方・自分・他の敵の手前で止まる）。**その先に敵がいれば、押し出した敵と押し出された敵は共に1ダメージ**を受けます。壁などで止まった時はダメージなし。途中の地雷は踏ませ、奈落に差しかかれば落ちます。2×2の敵も縦横なら押せます。鍛えると攻撃にダメージが付きます。
- **攻撃前の予告**：ノックバック武器を持って敵にカーソルを乗せると、押される先が白い矢印で、敵にぶつかる所が赤い衝突マークで、ぶつかってダメージを受ける敵に赤い「+1」が表示されます。
- **ぶつかった瞬間**：敵同士がぶつかると、衝突点に黄色い星と「ドンッ」、盤が小さく揺れ、少し遅れて黄色い「−1」が両方の上に出ます（壁で止まった時は小さな輪だけ）。
- 報酬カードには「この武器の攻撃はダメージを与えないが、敵を〜の一番奥までノックバックさせる。その先に敵がいれば、押し出した敵と押し出された敵は共に1ダメージを受ける。」と、文字が収まる広さのカードでは敵にぶつける例と壁で止まる例の動く図を載せます。武器カードの説明文はどれも「この武器の攻撃は〜」の口調で、図で分からない効果だけを書きます（入替の杖・王将の杖は「この武器の攻撃はダメージを与えないが、敵との位置を入れ替えることができる。」）。
- **盾打ち**（右1マス）：序盤の報酬に出ます
- **薙ぎ払い**（上・下の1マス）：通常の報酬に出ます
- **突風剣**（右上・右・右下）：ボス前の報酬（3マス武器）に出ます。斜めの敵は斜め外側へ押します

**中盤武器**
- **ハンマー**：歩の動き（右1マス）。攻撃は3ダメージで、叩いたマス・その上下・さらに右の3マス（計6マス）の敵全員に当たります。敵にカーソルを合わせると、揺れる範囲がオレンジで表示されます。

- **ハンマーの見た目**：ハンマー系を持つと、主人公はハンマーを持った立ち絵になり、攻撃では振りかぶり（0.2秒）→ 叩きつけ（衝撃の火花と石つぶて付き）の2コマで振り下ろします。叩きつけでは叩くマスへ素早く踏み込み、水色の残像が尾を引きます（振りかぶった姿もその場に薄く残って消える）。ハンマーの頭がマスに触れた瞬間に**ヒットストップ**（約0.11秒、全部がビタッと止まり、ハンマーの姿が白く光り、叩いたマスが白く光って輪が出る）が入り、その後にダメージと響きが入って、叩いたマスから響く範囲全体へ一つの地響きが広がります（盤面全体が上下中心に0.5秒揺れる。波が通るマスが光り、地割れが走り、砂ぼこりが舞い上がり、黄色と水色の火花と石つぶてが範囲の端まで飛ぶ。範囲の外にははみ出さない）。

**投げ槍兵**（HP1・AP2）：縦横に1マスずつ移動。攻撃範囲は、前方1マス空けた先の横3マス。範囲にプレイヤーがいれば、その場から槍を投げます（1ターン1回）。隣接しても殴らず、投げられる位置まで下がって投げます。

**弓兵**（HP1・AP2）：上下にだけ移動（1ターンに2マスまで）。左向きの香車のように一直線を射ます。射線上にプレイヤーが入ると構え、射線を赤い斜線で表示します（構えるとそのターンは終わり）。次のターンの1APで射ち、残りの1APで動くか構え直します。矢は射線上の最初のユニット（プレイヤー・味方の妖精・他の敵）に当たります。壁・大砲・障害物は矢を止めます。構えた後にプレイヤーが射線から逃げても、その射線に射ちます。

**盾兵**（HP1・AP1）：縦横に1マスずつ近づき、隣接したら攻撃します。盾は左（正面）に構えていて、真左の隣からの武器攻撃と、左から右へ飛んでくる魔弾・大砲・放電を防ぎます。斜め・跳び・上下・後ろからの攻撃は通ります。中盤の3戦に1体ずつ出ます。

**解析兵**（HP2・AP1）：縦横に1マスずつ近づき、隣接したら攻撃します。武器で攻撃されると、その武器を「解析」して頭の上に表示し、以後その武器のダメージは0になります（解析できるのは1本だけで、別の武器で殴られると上書き）。倒すには2種類の武器で1回ずつ当てる必要があります。妖精の攻撃は解析しません。中盤1戦目と3戦目に1体ずつ出ます。解析すると目の色がシアンからオレンジに変わります。

**最終決戦：監獄の王**（10×10。終盤3戦目の報酬とキャンプの後）：盤面が10×10になり、1マスを縮めて同じ場所に収める。
- **監獄の王**（3×3・HP10・AP1）：一番奥の中央の玉座にいて、**移動も攻撃もしない**。攻撃範囲は王将（自分に接する周囲1マス）で、そこは兵を復活させる場所としてだけ使う。この戦闘で死んだ兵を死んだ順に覚えていて、2ターンに1体まで、その範囲のうち主人公に一番近い空きマスへ復活させる（情報パネルに「次に蘇る」兵を表示）。倒すと残りの敵ごと戦闘に勝つ。HPが半分以下（残り5以下）になると**怒り状態**になり、咆哮とともに赤いオーラをまとい、要塞監獄が毎ターン2体ずつ兵を出すようになる。
- **要塞監獄**（2×2・HP3・動かない）：王の上下に1つずつ。毎ターン、ボス以外の敵からランダムに1体を隣へ出す。壊れても兵は出ない（瓦礫が残る）。
- 前線は、移動監獄・歩兵・重装兵・盾兵・解析兵が歩のように縦一列にぎっしり並んだ壁。投げ槍兵は桂馬の位置。
- 王と要塞は押し出し・重力・突進で動かせない（ノックバックしても動かず、ダメージもない）。暴食妖精にも食べられない。
- **演出**：戦闘開始時に画面が暗転し、玉座の間の絵（`boss_title`）とともに「最終決戦 / 監獄の王」を表示。怒り状態に入った瞬間は赤く閃いて暗転し、王の顔（`prison_king_portrait`）が飛び込んで「怒り狂った」と告げ、画面が揺れる。倒すと王から光の輪が弾け、白く飛んだあと「監獄の王、陥落」。演出の間は操作を止める（`scripts/fx/boss_cinematic.gd`）。
- **アニメーション**（`assets/sprites/boss/`、256pxのコマを横に並べたシート）：王は待機・怒り待機・兵の復活・被弾・崩れ落ち（最後のコマで止まる）、要塞は待機・兵を出す瞬間。要塞はHP2・1で壊れかけの絵になり、壊れると瓦礫（`prison_fortress_ruin`）が残る。最終戦の床は石の床（`boss_floor`）、王の足元は玉座の床（`boss_throne_floor`）。

**金将兵**（HP2・AP1）・**銀将兵**（HP1・AP2）：将棋の金・銀の動きをする、生きた駒の敵。前は常に左（プレイヤーの初期位置側）で、駒の尖った側が前です。動けるマスがそのまま攻撃範囲で、プレイヤーがそこにいれば攻撃、いなければ自分の動きで攻撃できるマスへの最短ルートを進みます。金は右斜め後ろ2マス、銀は上下と真右に動けない（攻撃もできない）ので、そこが安全地帯です。銀は中盤1・終盤1、金は中盤2・中盤3・終盤2に、終盤3には両方が出ます。

投げ槍兵と弓兵は中盤ステージから登場します。弓兵は構えると照準が赤く光る絵に変わります。

プレイヤーがそのマスに留まったら攻撃してくる敵には「！」マークが付きます（次の敵ターンを裏で試算して判定）。

編成は `scenes/formations/run_01〜03.tscn` と `run_boss_01.tscn` で、Godotの2Dエディターから編集できます（敵の種類に「馬」を追加しました）。馬は今のところ跳躍騎兵と同じ絵です。

## 戦闘と操作

移動・攻撃・妖精使用はそれぞれ **1 AP**。武器は下側のカードを1回クリックすると **0 APで即座に持ち替え**ます。向き変更はありません。APを残してターンを終了できます。

- 装備中の武器の範囲にある空きマスをクリックすると移動します。
- 範囲内の敵をクリックすると、その場から1ダメージを与えます。
- 敵がダメージを受けると、体が一瞬真っ白に光ってから赤く染まって戻り、攻撃の向きへ弾かれてつぶれ・揺れます。マスが白く光り、白と赤の輪と火花が広がり、大きなダメージ数字（実際のダメージ量）が弾んで浮かびます。盤面も揺れます。1×1・2×2・3×3の敵ごとに、輪・火花・揺れ・弾かれる量が大きさに合わせて大きくなります（`unit_view.gd` の `play_hit_reaction`、白い光は `scripts/fx/hit_flash.gdshader`、輪と数字は `battle_view.gd` の `_draw_enemy_hit`）。
- 戦闘盤面は水色の外枠（外側に柔らかい光、四隅に明るいかぎ形）で囲み、ゆっくり明滅します。8×8以上の盤面では左右のパネルに接しているので、光と角を枠の内側に収めます。
- 武器カードと報酬カードの小さな盤面で、移動・攻撃できるマスを確認できます。「前」は常に画面右です。
- 敵にカーソルを合わせると右側にHP・AP・行動範囲を表示します。右クリックで詳細を固定できます下の大きな一文は、盤面の「！」と同じ判定で、今のマスから動かなかった場合に次の敵ターンでその敵に攻撃されるかを示します（「このままだと攻撃される！」赤／「今の位置なら攻撃は届かない」水色）。突撃準備・弓を構えている・飛車の構えなど、その敵の今の状態はその下の小さな行に出ます。味方の暴食妖精も同じ書き方です。
- 設置物（槍砲・風見砲・花火・蓄電・壁精霊・隠密妖精・影縫い・加護の地・奈落・地雷・魔法陣の白マス）にカーソルを合わせると、右側に名前・残りターン・今の状態（大砲の向き、蓄電の溜まり「2 / 3」、影縫いの入れ替わり可否、加護の地の中にいるか）と、何をすると発動するかを表示します。
- 召喚した味方（どんぐり妖精・暴食妖精・一匹狼の妖精・聖精霊・聖騎士）も、カーソルを合わせると同じようにHP・AP・移動範囲（緑の●）・攻撃するマス（赤の×）と動き方を表示します（「次の行動」の一言は出さず、暴食妖精が次に主人公を噛む位置にいるときだけ赤字で警告します）。
- 妖精は左側の3枠に表示します。使用済みの枠も残り、次の戦闘で再び使えます。
- すべての武器で既存の剣の立ち絵・モーションを共用しています。

| 入力 | 操作 |
| --- | --- |
| 武器カード／`J`・`K`・`L`／マウスホイール | 対応する武器へ無料で持ち替え（ホイールは下で次の武器、上で前の武器へ、3本を一周） |
| 妖精カード／`1`・`2`・`3` | 対応する妖精を選択 |
| 盤面をクリック | 移動・攻撃・妖精の配置 |
| 魔弾の配置後に矢印を選ぶ | 発射方向を確定 |
| `Space`／左下のボタン | ターン終了 |
| `R` | 現在の装備で戦闘をやり直す |
| `H`／上部のボタン | ルールの表示 |
| 上部の「履歴」 | 戦闘履歴の表示 |
| `Esc`／右クリック | 妖精の選択を取り消す |
| `M` | BGMと効果音のミュート・解除 |

妖精は **1枠につき各戦闘1回、使用1 AP**。選択や配置先の確認では消費しません。同じ妖精を複数所持した場合も、枠ごとに使用回数を管理します。

どんぐり妖精の移動と攻撃はそれぞれ1 AP。召喚直後に自動で攻撃するのではなく、プレイヤーのターン終了を待ちます。配置した妖精・召喚した味方・地雷は次の戦闘へ持ち越しません。

初期妖精の候補と報酬候補は `scripts/run/run_model.gd` の `starting_fairy_pool` / `reward_fairy_pool` で分けています。初期候補はプールから重複なく3種類を抽選します。現在の初期プールは3種類なので全種類が並びます。追加時は `items/` の定義、`battle_model.gd` の `ITEMS`、抽選プールに登録してください。

## ステージの編集

`scenes/formations/run_01.tscn`〜`run_03.tscn` をGodotの **2Dエディター** で開きます。

1. 敵マーカーをドラッグします。マウスを離すと64px間隔のマス中央に揃います。
2. マーカーの複製・削除で数を変更します。
3. Inspectorの `enemy_kind` で種類を選びます。`Recruit` はHP1/AP1の歩兵、`Infantry` は従来のHP1/AP2の歩兵です。
4. ルートの `board_size` で盤面サイズ、`player_start` で開始位置を設定します。開始位置は水色の枠です。
5. 保存し、F5で初期ビルド選択から実行します。

同じマスに複数の敵を重ねず、水色のプレイヤー開始位置は空けてください。配置シーン単体は戦闘画面ではありません。

| 戦闘 | 盤面 | 初期配置 |
| --- | --- | --- |
| 1 | 4×4 | 右側にHP1/AP1の歩兵4体 |
| 2 | 5×5 | 右側中央の2×2にHP1/AP1の歩兵2体・重装兵2体を交互に配置 |
| 3 | 6×6 | 旧ステージ2を時計回りに90度回した配置。従来の歩兵4体・重装兵2体・地雷兵1体 |

HP1/AP1の歩兵と重装兵は到達可能な経路で接近し、隣接すると攻撃します。従来のAP2歩兵は包囲・突撃のAIを維持しています。地雷兵はプレイヤーが近づくと距離3まで離れ、2回目の行動で今いるマスに地雷を設置します。敵を右クリックまたはカーソルで選ぶと、右のパネルの下に**敵のクセ（2行）**を表示します（`battle_model.gd` の `HABITS`）。地雷は地雷兵以外の敵・味方に1ダメージを与えます。

旧 `encounter_*.tscn` は以前の配置資料として残してあり、現在の進行では読み込みません。

## Windowsへの書き出し

Godotのエクスポートテンプレートをインストールし、「プロジェクト → エクスポート」で既存の **Windows Desktop** プリセットを使います。出力先は `build/windows/ALAKAZAR.exe`、x86_64・ゲームデータ埋め込み設定です。

コマンドラインの場合は出力先フォルダを作成してから実行します。

```sh
mkdir -p build/windows
godot --headless --path . --export-release "Windows Desktop" build/windows/ALAKAZAR.exe
```

書き出した実行ファイルとGodotのキャッシュはGit管理対象外です。このリポジトリには開発用プロジェクトと素材を収録しています。

### BGM

`assets/audio/bgm/` のBGMは `tools/generate_bgm.py` で生成しています。全曲で同じ音色とキー（Dマイナー）を使い、サイバー風のサウンドトラックとして統一しています。音色は、フィルターを通したノコギリ波ベース、デチューンしたパッド、エコー付きのアルペジオ、控えめなリードです。キックに合わせて全体がうねる（サイドチェイン）ようにし、どの音も高域を抑えてゲームの邪魔をしない音量にしています。音の合成はPython標準ライブラリだけで行い、同じ内容なら毎回同じ音になります。書き出しは軽量なOgg Vorbis（モノラル・32kHz・約74kbps）で、戦闘BGMでも約600KBです。エンコードには `pip install soundfile` が必要です。

| `king_loop.ogg` | 最終ボス「監獄の王」戦のBGM（Cフリジアン・ドミナント・120BPMのハーフタイム・90小節、3分のループ）。監獄の鐘、鎖のジャラつき、鉄扉が閉まる音、鍵束のきらめき、玉座の間のオルガンと這うようなベース。門（鐘と心音）→ 行進 → 王のモチーフ → 普段の戦闘曲のメロディをハ短調の暗い合唱で引用 → 高まり → 2本のリードの頂点 → 鐘と心音だけの静寂 → 行進の再現 → 先頭へ |
| `king_rage.ogg` | 監獄の王の怒り状態版。`king_loop.ogg` と1サンプル単位で同じ長さ・同じ拍で、ドラムが倍速、サイレン、拍ごとの鐘の乱打、歪んだベース、メロディが1オクターブ上。ゲームでは2つを同時に再生し、王のHPが半分以下になった瞬間に0.5秒で切り替える |
| `king_victory.ogg` | 監獄の王の撃破ジングル。鎖が1本ずつちぎれ、鉄扉と大鐘が鳴り、普段の戦闘曲のメロディが初めてDメジャーで鳴り響く |
| `victory.ogg` | 勝利ジングル（上昇アルペジオからDメジャーで解決） |
| `defeat.ogg` | 敗北ジングル（戦闘のパッドがテープストップして沈む） |
| `king_intro.ogg` | 最終決戦の開始時、暗転の間に鳴る登場曲（約4秒）。闇の中で鉄扉が閉まり、オルガンが膨らみ、王の名前と同時に大鐘と王のモチーフ。鳴り終わってから `king_loop.ogg` が頭から始まる |
| `king_rage_sting.ogg` | 怒り状態に入った瞬間の合図（約2.6秒）。鎖がちぎれ、サイレン、歪んだ咆哮、半音ぶつかる鐘と不協和のオルガン。この間はBGMを下げる |
| `king_fall.ogg` | 王を倒した瞬間（約3秒）。鎖が次々に弾け、白く飛ぶ瞬間に大きな一撃、Cメジャーの上で鐘が鳴り響く。そのあと撃破ジングルへ |
| `rotorick_intro.ogg` | ロトリック戦の開始合図（約2秒）。リールが回って止まり、ブザーとAハーモニックマイナーの一撃。鳴り終わってからロトリックの曲が始まる |

曲を変更する場合は、スクリプト内の構成と各セクションの音量（`SECTIONS`）、コード進行（`CHORDS`）、フック（`HOOK`）を編集してから次のコマンドで再生成します。

```sh
python3 tools/generate_bgm.py
python3 tools/generate_bgm.py draft_loop.ogg camp_loop.ogg  # 指定した曲だけ
```

戦闘BGMはループ前提で循環的に書き出しており、終端のエコーやパッドの余韻が先頭につながります。Vorbisはサンプル数をそのまま保つため、インポート設定（`battle_loop.ogg.import` の `loop=true`）で継ぎ目なくループ再生されます。再生成してもこの設定はそのまま使われます。

### 効果音

効果音はうるさくならないよう最小限で、**足音**（主人公 `step`・敵 `enemy_step`）、**攻撃**（剣の振り `sword_swing`、ハンマーの着弾 `hammer_slam`。この2つは外部で作った録音素材で、一番大きい瞬間が攻撃の当たる瞬間＝ハンマーはヒットストップの瞬間に重なるよう、少し前から鳴らす）、**大砲の誘爆**（8bit風の「ピコン」`chain_01`〜`chain_20`。D5から1連鎖ごとに半音上がり、20連鎖でA6。音程のゆらぎは付けない）と**監獄の王戦**の音だけです：兵の復活 `king_revive`、要塞が兵を出す `fortress_spawn`、王への被弾 `king_hit`、要塞にひび `fortress_crack`、要塞の崩壊 `fortress_collapse`、王が崩れ落ちる `king_collapse`。ほかにボス戦のジングル（王の登場・怒り・陥落、ロトリックの登場）があります。

`assets/audio/sfx/` の音は `tools/generate_sfx.py` で生成しています（`pip install numpy soundfile`）。全部の音を同じ作り方（布・木・石・鉄などの素材、同じ石造りの部屋の残響、同じ仕上げと音量の基準）にそろえています。ゲームでは `scripts/audio/sfx_player.gd` が鳴らし、毎回ピッチを少しずらします。どのイベントで鳴らすかは `battle_view.gd` の `_event_sound` にあります。

```sh
python3 tools/generate_sfx.py
python3 tools/generate_sfx.py king_hit step  # 指定した音だけ
```

## 自動テスト

初回は素材をインポートしてください。

```sh
godot --headless --editor --path . --quit
godot --headless --path . --script res://tests/test_run.gd
godot --headless --path . --script res://tests/test_run_ui.gd
godot --headless --path . --script res://tests/test_sword_animation.gd
godot --headless --path . --script res://tests/test_weapon_effects.gd
godot --headless --path . --script res://tests/test_heavy_behavior.gd
godot --headless --path . --script res://tests/test_cavalry.gd
```

`test_run.gd` はビルド選択・配置・固定方向・無料持ち替え・各妖精・交換・60シードの戦闘を検証します。`test_run_ui.gd` は実際のクリック入力を通して、画面遷移・妖精使用・12種類の武器モーション・報酬交換を検証します。旧 `test_battle.gd` / `test_items.gd` / `test_facing.gd` の呼び出し先は新しいルール検証へ統合しています。
