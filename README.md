# ALAKAZAR

武器と向きを切り替え、妖精の力で敵の包囲を突破するターン制タクティクスゲームです。
現在は6×6の盤面で3戦を遊べる、Godot製の開発中プロトタイプです。

## 起動

動作確認環境は **Godot 4.7.2（GDScript／GL Compatibility）** です。

1. このリポジトリをクローン、またはZIPでダウンロードして展開します。
2. Godotのプロジェクトマネージャーで `project.godot` をインポートします。
3. 素材のインポート完了後、**F5**でゲームを実行します。

Godotを `godot` コマンドで呼び出せる場合は、リポジトリ直下で次のコマンドも使えます。

```sh
godot --editor --path .
```

## 遊び方

各戦闘は敵ターンから始まり、敵とプレイヤーが交互に行動します。プレイヤーはHP5・AP2、初期装備は**銀／ソード**、初期の向きは画面上です。

移動・攻撃・武器の持ち替え・向きの変更・妖精の使用は、それぞれ **1 AP** を消費します。APを使い切るか「ターン終了」を押すと敵が行動し、次の自分のターンにAPが2へ戻ります。

- 空きマスをクリックすると移動、攻撃範囲内の敵をクリックすると1ダメージを与えます。攻撃ではプレイヤーの位置は変わりません。
- 武器や向きのプレビューは無料です。変更は「装備する 1 AP」「この向きにする 1 AP」で確定します。武器をプレビューしたまま盤面を操作しても、装備中の武器で行動します。
- 移動や攻撃で向きは自動変更されません。剣の攻撃モーションも現在の向きを使います。
- 敵を全滅させると勝利し、次の戦闘へ進めます。HPが0になると敗北です。
- 次の戦闘ではHP・装備・向きが初期状態に戻り、手札の残数だけを引き継ぎます。やり直しでは手札も初期状態に戻ります。

### 操作

| 入力 | 操作 |
| --- | --- |
| `1` / `2` / `3` | 銀／ソード・金／ハンマー・桂／アックスをプレビュー |
| `Q` / `E` / `Tab` | プレビューする武器を切り替え |
| 「装備する 1 AP」 | プレビュー中の武器を装備 |
| 「向き変更」／盤面のプレイヤーをクリック | 向きの選択を開く・閉じる |
| 「この向きにする 1 AP」 | 選択した向きを確定 |
| `↑` / `→` / `↓` / `←` | 向き変更中はプレビュー、魔弾精霊の配置後は発射方向を確定 |
| 手札をクリック／`4` `5` `6` `7` `8` `9` `0` | 左から1〜7枚目の妖精を選択。使用後はカードが詰まる |
| `B` | 左端の手札を選択・選択解除 |
| `Space` | ターン終了 |
| `R` | 現在の戦闘をやり直す |
| `H` | ルールを開く・閉じる |
| 上部の「履歴」 | 戦闘履歴を表示 |
| 右クリック | 妖精・向き選択中はキャンセル。それ以外は敵の詳細表示を固定・解除 |
| `Esc` | 武器プレビュー・履歴・妖精・向き選択・ルールを閉じる |
| `M` | BGMのミュート・解除 |

敵にカーソルを重ねると、右側にHP・AP・移動／攻撃範囲を表示します。攻撃範囲外の敵は左クリックでも詳細を固定できます。範囲図は基本3×3、跳躍騎兵は5×5です。

### 武器

移動範囲と攻撃範囲は共通で、「前」はプレイヤーが向いている方向を指します。

| 武器 | 移動・攻撃範囲 |
| --- | --- |
| 銀／ソード | 前・前斜め2方向・後ろ斜め2方向 |
| 金／ハンマー | 前・前斜め2方向・左右・後ろ |
| 桂／アックス | 前へ2マス＋左右へ1マスの2か所。途中の駒や地雷を飛び越える |

### 妖精の手札

手札は盤面下に左寄せで常時表示され、**合計7枚まで**持てます。同じ妖精を複数持つ場合も1枚ずつ表示します。開始時は3種類を各1枚所持します。

カードの選択や配置先の確認は無料で、発動時に **1 APと1枚** を消費します。選択すると右側に説明と効果のプレビューが表示されます。

| 妖精 | 効果 |
| --- | --- |
| 魔弾精霊 | 装備中の武器の攻撃範囲にある空きマスへ配置し、縦横の発射方向を指定。直線上の敵すべてに1ダメージ。敵を貫通し、障害物・設置済み隠密妖精で止まる |
| 隠密妖精 | 武器の攻撃範囲にある空きマスへ配置。通行をふさぎ、縦横に隣接した敵1体へ1ダメージを与えて消える。配置時点で隣接している敵にも発動する |
| ワープ妖精 | 敵・障害物・隠密妖精がない任意のマスへ瞬間移動。着地先の地雷は踏む |

魔弾精霊は配置後、矢印ボタン・矢印キー・配置マスと同じ行または列のマスを使って発射方向を確定します。設置済みの隠密妖精は次の戦闘へ持ち越しません。

### 敵と地雷

| 敵 | HP | AP | 行動 |
| --- | --- | --- | --- |
| 歩兵 | 1 | 2 | 縦横1マス。安全に近づけるマスを優先し、包囲・突撃予告を行う。隣接時や移動＋攻撃が可能な場合は予告なしでも攻撃する |
| 地雷兵 | 1 | 2 | 縦横1マス。プレイヤーから距離3付近へ移動し、その場に地雷を設置する。自身は地雷を踏まない |
| 重装兵 | 2 | 1 | 縦横1マス。武器の攻撃範囲や地雷を避けず、通行可能な経路でプレイヤーへ接近する。障害物や他の敵を回り込むことがある |
| 跳躍騎兵 | 1 | 2 | 縦横1マス＋向いている方向への桂馬跳び。攻撃を最優先し、接近できる桂馬跳びを優先する。跳べず距離がある場合は、有効な跳躍先を作れる向きへ1 APで旋回する |

歩兵の黄色い「！」は、次の敵ターンの突撃予告です。プレイヤーから距離2以内に複数の歩兵がいる、包囲が続く、または歩兵が残り1体になると予告が発生します。通常時の歩兵は近づける移動先だけを候補にし、安全な前進ができなければ評価に応じて待機することがあります。

地雷は敵味方を問わず、踏んだユニットへ1ダメージを与えて消えます。地雷兵だけは無効です。桂馬跳びは着地先で地雷を判定します。重装兵は地雷を避けません。

## ステージの編集

`scenes/formations/encounter_01.tscn`〜`encounter_03.tscn` をGodotの**2Dエディター**で開きます。

1. 敵マーカーをドラッグして配置します。マウスを離すと64px間隔のマス中央に揃います。
2. 敵を増やす場合はマーカーを複製し、減らす場合は削除します。
3. Inspectorの `enemy_kind` で `Infantry`・`Miner`・`Heavy`・`Cavalry` を選びます。
4. 保存後、F5でゲーム全体を実行して確認します。

1マスに複数の敵を重ねず、プレイヤーの開始位置 **左から3列目・上から6行目** は空けてください。配置シーン単体は戦闘画面ではありません。

現在の編成は次のとおりです。

| ステージ | 歩兵 | 地雷兵 | 重装兵 | 跳躍騎兵 |
| --- | --- | --- | --- | --- |
| 1 | 2 | 2 | 2 | 0 |
| 2 | 4 | 1 | 2 | 0 |
| 3 | 2 | 0 | 1 | 1 |

## Windowsへの書き出し

Godotのエクスポートテンプレートをインストールし、「プロジェクト → エクスポート」で既存の **Windows Desktop** プリセットを使います。出力先は `build/windows/ALAKAZAR.exe`、x86_64・ゲームデータ埋め込み設定です。

コマンドラインの場合は出力先フォルダを作成してから実行します。

```sh
mkdir -p build/windows
godot --headless --path . --export-release "Windows Desktop" build/windows/ALAKAZAR.exe
```

書き出した実行ファイルとGodotのキャッシュはGit管理対象外です。このリポジトリには開発用プロジェクトと素材を収録しています。

## 開発用の構成

| 場所 | 内容 |
| --- | --- |
| `scripts/battle_model.gd` | 盤面・HP/AP・武器・向き・手札・勝敗 |
| `scripts/battle_view.gd` | UI・入力・ターン進行・演出の制御 |
| `scripts/enemy_planner.gd` | 敵ターン、歩兵の包囲位置、地雷兵・跳躍騎兵の行動 |
| `scripts/infantry_behavior.gd` / `scripts/heavy_behavior.gd` | 歩兵・重装兵それぞれの移動判断 |
| `scripts/unit_view.gd` / `scripts/animation/sword_motion.gd` | キャラクター描画・剣の方向別アニメーション |
| `scripts/weapon_effect.gd` | 武器別エフェクト |
| `scripts/audio/bgm_player.gd` | BGMの再生（戦闘中はループ、結果画面で勝利・敗北ジングル） |
| `scripts/movement/` | 金・銀・桂の移動パターン |
| `items/` / `scripts/items/` | 妖精の定義・効果・手札UI |
| `scenes/formations/` | 2Dエディターで編集する敵配置 |
| `assets/` | キャラクター・エフェクト・UI・フォント・BGM |
| `tests/` | Godotで実行する自動テストと描画キャプチャ |
| `tools/` | 剣アニメーションの画像検証用スクリプト・BGM生成スクリプト |

妖精を追加する場合は `items/` に定義用 `.tres` を作り、`battle_model.gd` の `ITEMS` に登録します。効果は `apply(model, cell, direction)` を実装したスクリプトで定義します。所持数の追加には、合計7枚の上限を適用する `add_item()` を使います。

### BGM

`assets/audio/bgm/` のBGMは、ファミコン風の音源（パルス波2ch・三角波ベース・ノイズドラム）を模した `tools/generate_bgm.py` で生成しています。Python標準ライブラリだけで動作し、同じ内容なら毎回同一のWAVを出力します。

| ファイル | 内容 |
| --- | --- |
| `battle_loop.wav` | 戦闘BGM（Aマイナー・150BPM・16小節、約25.6秒のループ） |
| `victory.wav` | 勝利ジングル |
| `defeat.wav` | 敗北ジングル |

曲を変更する場合は、スクリプト内のメロディ・コード進行を編集してから次のコマンドで再生成します。

```sh
python3 tools/generate_bgm.py
```

戦闘BGMのWAVにはループ位置を記録した `smpl` チャンクが入っており、Godotの既定のインポート設定（Detect From WAV）でループ再生されます。

## 自動テスト

初回はGodotエディターでプロジェクトを開いて素材をインポートするか、次のコマンドを実行します。

```sh
godot --headless --editor --path . --quit
```

テストはリポジトリ直下から個別に実行できます。

```sh
godot --headless --path . --script res://tests/test_battle.gd
```

2026-09-24にGodot 4.7.2で実行した結果です。

| テスト | 結果 |
| --- | --- |
| `test_items.gd` | 成功（3,844チェック） |
| `test_weapon_effects.gd` | 成功（51チェック） |
| `test_cavalry.gd` | 成功 |
| `test_heavy_behavior.gd` | 成功 |
| `test_sword_animation.gd` | 成功（52チェック） |
| `test_battle.gd` | 26,865チェック中211失敗 |
| `test_facing.gd` | 29チェック中2失敗 |

失敗には、金が初期装備であることや重装兵が危険を避けることなど、旧仕様を前提にしたチェックが含まれます。失敗数は独立した不具合の件数ではありません。テストの期待値と現行仕様の照合は未完了です。

画像検証用のPythonスクリプトにはPillowが必要です。`build_sword_review.py` はmacOSのMenloフォントと、リポジトリ外の `../animation-review/` にある比較用キャプチャを参照する開発用ツールです。これらの比較素材は本リポジトリには含めていません。

## 素材・元プロジェクト

「Ruins Delver Prototype」から素材・描画デザイン・移動コードを引き継ぎ、独立したプロジェクトとして開発しています。取り込み時の素材記録は [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md) にあります。その後に追加・差し替えた素材をすべて網羅する一覧ではありません。

フォントのライセンスは `assets/fonts/OFL-*.txt` に収録しています。
