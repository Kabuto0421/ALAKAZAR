# ALAKAZAR

武器ごとに異なる移動・攻撃範囲と妖精のスキルを組み合わせて戦う、Godot製のターン制タクティクスです。初期ビルドを選び、4×4・5×5・6×6の3戦を攻略しながら報酬で構成を更新するプロトタイプです。

## 起動

動作確認環境は **Godot 4.7.2（GDScript／GL Compatibility）** です。Godotで `project.godot` をインポートし、素材の読み込み後に **F5** で実行してください。戦闘画面ではなく初期ビルド選択から始まります。

```sh
godot --editor --path .
```

## 探索の流れ

**追加ルール（最初の武器・妖精選びの画面の上部で切り替え。初期は全部OFF＝今までどおり）**

| ルール | 内容 |
|---|---|
| 包囲の輪 | 4ターンごとに、盤の外周から1周ずつ「包囲」される（中央の2×2〜3×3は最後まで残る）。狭まる直前のターンは、その輪が赤く点滅し、ターン表示の横に「包囲まで Nターン」を表示。包囲の中にいると、敵ターン開始時に1ダメージ（敵・味方も同じ）。押し出しで敵を輪へ追い込める |
| 同士討ち | 投げ槍は3マスの範囲にいる敵にも当たる。突進くん・ロトリックの突進は、避けられて敵にぶつかったらその敵に1、プレイヤーごと押して壁に挟んだ敵にも1。弓の矢は、このルールがなくても敵に当たる |
| 連撃 | 1回の行動（攻撃・妖精・大砲の起爆など）で敵を2体以上倒すと、APが1戻る（「連撃！ AP+1」と表示） |

切り替えはその遠征の間ずっと有効で、「初期ビルドを選び直す」でも引き継ぎます（保存はしない）。

**遊び方（ゲーム内）**：画面右上の「遊び方 [H]」か H キーで、8ページの説明（基本・AP・武器・特殊効果・妖精・設置系の妖精・敵にもAPがある・危険を読む）を開けます。各ページはルールを2行で書き、実際のゲーム画面のスクショで見せます。スクショはパラパラ漫画のようにループ表示し（APを使い切る→敵のターン→またあなたのターン、など）、「移動 −1 AP」「持ち替え 0 AP」などのタグでAPの使い方を毎回見せます。スクショは `assets/help/` にあり、画面のデザインが変わったら `xvfb-run godot --rendering-driver opengl3 --path . --script res://tools/capture_help.gd` で撮り直せます（ゲーム起動時には撮影しません）。ゲームを起動して最初の戦闘では自動で1回だけ開きます（どこにも保存しないので、起動するたびに1回出ます）。

**戦闘1（4×4）→ 戦闘2（5×5）→ 戦闘3（6×6）→ キャンプ → ボス戦（7×7）** の順に進みます。

1. 右隣だけに動ける「前進剣」と左隣だけに動ける「後退剣」に、3本目を追加します。候補は、序盤用の武器のうち上下両方へ行ける序盤用の武器12種から3つ抽選されます。妖精選択から「← 武器選択」で戻っても、候補は変わりません。
2. 武器を選ぶと、魔弾精霊・隠密妖精・どんぐり妖精から1つを選ぶ画面に進みます。
3. 戦闘は**プレイヤーの手番から**始まります。プレイヤーは左側・右向き、敵は左向きで固定です。
4. 全滅させると妖精の使用回数が回復し、武器3候補・妖精2候補から報酬を1つ選びます（何も取らずに進むこともできますが、おまけはありません）。
5. 武器・妖精はそれぞれ最大3枠。満杯なら手放す装備を選んで交換します。交換を取り消して同じ報酬候補に戻ることや、報酬を取らずに進むこともできます。
6. 戦闘3の報酬の後は**キャンプ**です。次のどれか1つを選びます。
   - **休む**：HP+2（最大5）
   - **鍛える**：所持している武器を1本選び、攻撃力+1。1本につき1回まで
   - **妖精のクラスアップ**：所持している妖精を1体選び、効果を強化。1体につき1回まで（斬撃精霊だけは飛刃精霊に進化）

   強化した武器・妖精は、名前に黄色い「+」が付き、アイコンや範囲図の角に黄色い四角の「+」バッジが付きます（盤面に置いた妖精にも付きます）。クラスアップした妖精を報酬の交換で手放すと、強化も失われます。

   | 妖精 | クラスアップ後 |
   |---|---|
   | 魔弾精霊+ | 選んだ向きとその反対向きの両方に撃つ |
   | 斬撃精霊 → 飛刃精霊 | 3マス幅の斬撃を向きの先まで飛ばす（進化） |
   | 隠密妖精+ | 縦横に隣接する敵すべてに1を与えて消える |
   | どんぐり妖精+ | HP2になり、斜めの敵も攻撃する |
   | ワープ妖精+ | 0 APで使える |
   | 壁精霊+ | 向きを選び、その向きへ一直線に3マスの壁を置く（ふさがったマスの手前まで） |
   | 槍砲精霊+ | 叩くと前後2方向に撃つ |
   | 風見砲の妖精+ | 叩くと前後2方向に撃ち、向きが時計回りに回る |
   | 花火妖精+ | 爆発が自分と味方を巻き込まない |
   | 蓄電の妖精+ | 最初から電気が1溜まっている（2回叩けば放電） |
   | 影縫い精霊+ | 入れ替わった先の縦横に隣接する敵すべてに1 |
   | 一匹狼の妖精+ | HP2になり、噛んで倒すと隣の敵にもう一度噛みつく |
7. キャンプの後は**ボス戦**：7×7の盤で、HP2の馬3体と戦います。倒すと遠征達成です。

**HPは戦闘をまたいで持ち越し、勝つたびに1回復します**（難易度を上げると回復なし。`run_model.gd` の `difficulty` を1以上にすると無効。最大5。戦闘中の `R` では、その戦闘を始めたときのHPに戻ります）。妖精の使用回数は戦闘ごとに回復し、獲得した装備と鍛えた攻撃力は引き継ぎます。

### 序盤の編成

AP2の歩兵を、AP1の重装兵の後ろに置いています。重装兵が道をふさぐので歩兵は動きにくい一方、2体がそろって迫ると強い組み合わせです。

| 戦闘 | 盤 | 敵 |
| --- | --- | --- |
| 1 | 4×4 | 重装兵＋後ろにAP2歩兵、AP2歩兵 |
| 2 | 5×5 | 重装兵＋後ろにAP2歩兵、単独のAP2歩兵×2、地雷兵 |
| 3 | 6×6 | 重装兵＋AP2歩兵のペアを上下に2組、跳躍騎兵（初登場）、地雷兵 |
| ボスA | 7×7 | 馬（HP2・AP2、跳躍騎兵と同じ動き）×3 |
| ボスB | 6×6 | 突進くん＋移動監獄（どちらも2×2マス） |
| 中盤1 | 6×6 | 重装兵＋AP2歩兵、投げ槍兵×2、跳躍騎兵 |
| 中盤2 | 6×6 | 弓兵、重装兵＋AP2歩兵、投げ槍兵、地雷兵、跳躍騎兵 |
| 中盤3 | 7×7 | 弓兵×2（上下の端）、重装兵＋AP2歩兵、重装兵、投げ槍兵、跳躍騎兵、地雷兵 |

**魔法陣の武器**（レア）：報酬の武器にまれに「魔法陣」の付いたものが出ます（序盤10%、最初のボスの後は30%。弓には付きません）。魔法陣の武器は攻撃できず（敵や大砲は選べない）、移動だけができます。移動すると、立っていたマスと着地したマスが白くなり、戦闘の間ずっと残ります。白いマス（斜めにつながっていてもよい）で囲碁のように囲むと、囲った内側と白線の上にいる敵すべてに**99ダメージ**。盤の端は壁になりません。使った白線は消えます。移動先にカーソルを乗せると、そこで囲める範囲が金色に光ります。ダメージ床（ロトリックの出目4）は白いマスの上に重ねて表示されます。

影縫い精霊と一匹狼の妖精は**終盤の妖精**で、ロトリックを倒した後の報酬にだけ出ます。王将剣・竜王槍などの広い武器を持つほど置ける場所が減るので、どちらを取るかの駆け引きになります。

ボス（最初のボス・ロトリック）を倒した後の報酬では、30%の確率で妖精の候補の1枠が**レア妖精**（風斧精霊か聖精霊）になります。

最初のボスは、キャンプに着いた時点でボスAかボスBのどちらかが抽選されます（キャンプ画面に表示）。

**突進くん**（HP3・AP1・2×2）：青・左向きで登場し、少し間をおいて、プレイヤーの最初のターンの前に赤く構えます（ボス演出）。以後は毎ターン、構えた向きへ飛車のように突進（1 AP）し、突進後すぐにプレイヤーへ構え直します。2マス幅の突進路は赤い斜線で表示されます。突進路にいると1ダメージを受け、突進くんと一緒に壁まで押し込まれます。避けた場合は、プレイヤーと同じ軸に並ぶところまで進んで止まり、そちらへ構え直します。突進路にある壁精霊・大砲（全種）・隠密妖精・影縫い精霊の影・味方・障害物は粉砕し、その手前で止まります（赤い斜線の突進路もそこで途切れます）。盤面の端では止まります。他の敵は、プレイヤーが突進路にいるときはプレイヤーごとまとめて押し出し（押された敵にダメージはなし）、プレイヤーが避けているときは壊さずその手前で止まります。

**移動監獄**（HP1・AP1・2×2）：縦横に1マスずつ近づき、プレイヤーが辺に接していれば攻撃します。壊すと、占めていた2×2の斜めの2マスに**執行兵**（HP2・AP2、重装兵と同じく真っすぐ迫って攻撃）が2体現れます。

2×2の敵は、どのマスを攻撃しても本体に当たります。魔弾や大砲の直線が2マス分を通っても、1回の効果で当たるのは1回だけです。

3戦目（序盤・中盤とも）の報酬はボス前の特別報酬で、武器の候補が3マスの強い武器になります（4マスの十字剣・交差剣は出ません）。候補は突進・上弦・扇・天秤・飛燕・見返・城楼・丁字・突風の3マス9本と、香車槍の10本です。

ボスを倒すと報酬を選んで中盤3戦に進み、中盤キャンプを経て**ロトリック**（8×8）と戦います。ロトリックを倒すと報酬を選んで**終盤3戦**に進みます（今ある敵で組んだ最も強い編成の仮ステージ。BGMはボス曲）。終盤2の後にキャンプがあり（終盤で手に入れた武器・妖精もここで強化できる）、終盤3を倒すと遠征達成です（この先のボスはまだない）。

| 終盤 | 盤面 | 敵 |
|---|---|---|
| 1 | 7×7 | 突進くん・盾兵2・弓兵2・解析兵・執行兵 |
| 2 | 7×7 | 移動監獄・馬2・投げ槍兵2・地雷兵・重装兵・執行兵 |
| 3 | 8×8 | 突進くん・移動監獄・執行兵2・弓兵・馬・跳躍騎兵・盾兵・解析兵・投げ槍兵 |

**ロトリック**（HP7・AP1・2×2）：胸のリール1つで効果を決めるスロットのボス。本体は常に正面向きで、突進の向きと準備状態は本体の外側の赤い矢印（出目5で停止中は、内向きの黄色い矢印が本体を取り囲む）、実際の突進路は盤面の赤い斜線で示します。移動と突進は突進くんと同じ飛車の動きです。登場後、最初のターンの前に向きと出目を提示し、毎ターン「出目の効果 → 突進 → 構え直し → 次の出目（0 AP）」の順に動きます。出目は同じ目が続かず、7は出にくくなっています。敵情報には、執行者の口調のセリフと、実際の効果を並べて表示します。

| 出目 | 効果 |
|---|---|
| 1〜3 | そのプレイヤーターンは、武器を1〜3枠目の1本しか使えない（他は「封印」） |
| 4 | 赤黒の市松のマスに、次の敵ターン開始時にいると1ダメージ（敵・味方も。ロトリック自身は除く） |
| 5 | エラーで停止。次の敵ターンは突進しない（HPは減らない） |
| 6 | 今いる場所に紫のホログラムの残像（2×2）を残してから突進。残像は隣に来たプレイヤーを1回斬って消える。倒さなくても勝利できる |
| 7 | AP+1（合計2）。1回目の突進は、避けても回り込んで必ず当たる（壁精霊などを置いても、粉砕してから追いかけてくる）。続けてもう1回突進。突進が何回も続くときは、1回ごとに一度止まってから次の突進に移る |ボス戦以降の報酬では、武器の1枠が中盤武器（ハンマー・弓）になります。

**押し出し（ノックバック）武器**
攻撃が当たって生き残った敵を、攻撃した向き（自分→敵）へ1マス押し出します。押し出せない（盤の端・壁精霊・障害物・大砲・他の敵・自分）ときはぶつかって追加で1ダメージ（ダメージを受けるのは押された敵だけで、ぶつけられた側の敵は無傷）。押した先の地雷は踏ませます。2×2の敵も縦横なら押せます。
- **盾打ち**（右1マス）：序盤の報酬に出ます
- **薙ぎ払い**（上・下の1マス）：通常の報酬に出ます
- **突風剣**（右上・右・右下）：ボス前の報酬（3マス武器）に出ます。斜めの敵は斜め外側へ押します

**中盤武器**
- **ハンマー**：歩の動き（右1マス）。攻撃は3ダメージで、叩いたマス・その上下・さらに右の3マス（計6マス）の敵全員に当たります。敵にカーソルを合わせると、揺れる範囲がオレンジで表示されます。
- **弓**：角の動きで、斜め4方向の一直線上で最初にいる敵を射ます（1ダメージ）。移動はできません。装備中は射線を緑の点で表示します。妖精は射線上の空きマス（最初の敵の手前まで）に置けます。絵は仮で剣のままです。

**投げ槍兵**（HP1・AP2）：縦横に1マスずつ移動。攻撃範囲は、前方1マス空けた先の横3マス。範囲にプレイヤーがいれば、その場から槍を投げます（1ターン1回）。隣接しても殴らず、投げられる位置まで下がって投げます。

**弓兵**（HP1・AP2）：上下にだけ移動（1ターンに2マスまで）。左向きの香車のように一直線を射ます。射線上にプレイヤーが入ると構え、射線を赤い斜線で表示します（構えるとそのターンは終わり）。次のターンの1APで射ち、残りの1APで動くか構え直します。矢は射線上の最初のユニット（プレイヤー・味方の妖精・他の敵）に当たります。壁・大砲・障害物は矢を止めます。構えた後にプレイヤーが射線から逃げても、その射線に射ちます。

**盾兵**（HP1・AP1）：縦横に1マスずつ近づき、隣接したら攻撃します。盾は左（正面）に構えていて、真左の隣からの武器攻撃と、左から右へ飛んでくる魔弾・大砲・放電を防ぎます。斜め・跳び・上下・後ろからの攻撃は通ります。中盤の3戦に1体ずつ出ます。

**解析兵**（HP2・AP1）：縦横に1マスずつ近づき、隣接したら攻撃します。武器で攻撃されると、その武器を「解析」して頭の上に表示し、以後その武器のダメージは0になります（解析できるのは1本だけで、別の武器で殴られると上書き）。倒すには2種類の武器で1回ずつ当てる必要があります。妖精の攻撃は解析しません。中盤1戦目と3戦目に1体ずつ出ます。解析すると目の色がシアンからオレンジに変わります。

投げ槍兵と弓兵は中盤ステージから登場します。弓兵は構えると照準が赤く光る絵に変わります。

プレイヤーがそのマスに留まったら攻撃してくる敵には「！」マークが付きます（次の敵ターンを裏で試算して判定）。

編成は `scenes/formations/run_01〜03.tscn` と `run_boss_01.tscn` で、Godotの2Dエディターから編集できます（敵の種類に「馬」を追加しました）。馬は今のところ跳躍騎兵と同じ絵です。

## 戦闘と操作

移動・攻撃・妖精使用はそれぞれ **1 AP**。武器は下側のカードを1回クリックすると **0 APで即座に持ち替え**ます。向き変更はありません。APを残してターンを終了できます。

- 装備中の武器の範囲にある空きマスをクリックすると移動します。
- 範囲内の敵をクリックすると、その場から1ダメージを与えます。
- 武器カードと報酬カードの小さな盤面で、移動・攻撃できるマスを確認できます。「前」は常に画面右です。
- 敵にカーソルを合わせると右側にHP・AP・行動範囲を表示します。右クリックで詳細を固定できます。
- 妖精は左側の3枠に表示します。使用済みの枠も残り、次の戦闘で再び使えます。
- すべての武器で既存の剣の立ち絵・モーションを共用しています。

| 入力 | 操作 |
| --- | --- |
| 武器カード／`1`・`2`・`3` | 対応する武器へ無料で持ち替え |
| 妖精カード／`4`・`5`・`6` | 対応するスキルを選択 |
| 盤面をクリック | 移動・攻撃・妖精の配置 |
| 魔弾の配置後に矢印を選ぶ | 発射方向を確定 |
| `Space`／左下のボタン | ターン終了 |
| `R` | 現在の装備で戦闘をやり直す |
| `H`／上部のボタン | ルールの表示 |
| 上部の「履歴」 | 戦闘履歴の表示 |
| `Esc`／右クリック | 妖精の選択を取り消す |
| `M` | BGMのミュート・解除 |

## 武器と妖精

武器は24種類の移動パターンを用意しています。各武器の移動範囲と攻撃範囲は同じで、攻撃はすべて1ダメージです。パターンの定義は `scripts/run/weapon_catalog.gd` にあります。

**仕組みの違う武器**

| 武器 | 仕組み | 出る時期 |
|---|---|---|
| 香車槍 | 右へ、ふさがるまで一直線に滑る。途中の最初の敵（または大砲）を攻撃 | ボス前の報酬 |
| 飛車槍 | 縦横4方向へ滑る。魔法陣を付けると通った道がすべて白くなる | ロトリックの後（終盤枠） |
| 角剣 | 斜め4方向へ滑る | ロトリックの後（終盤枠） |
| 竜王槍 | 縦横4方向へ滑り、斜めにも1マス | ロトリックの後（終盤枠） |
| 竜馬剣 | 斜め4方向へ滑り、縦横にも1マス | ロトリックの後（終盤枠） |
| 八方桂剣 | 桂馬の8方向すべてに跳ぶ | 最初のボスの後（中盤枠） |

序盤は1マスずつ構成を広げます。**最初の3本目の武器と、3戦目までの報酬の武器は、序盤用の武器**から抽選します。序盤用は「2マスで、少なくとも1マスは途中を飛び越えて跳ぶ」ヘンテコな武器です（純粋な跳び2マスのほか、雁行・跳上・蛇行など隣1マス＋跳び1マスの組み合わせもあります）。2マスなので十字剣（4マス）より必ず弱くなります。左右反転しただけの兄弟武器は整理して1本にまとめています（全45本。滑る4本はロトリックの後、金将剣などの広い武器は最初のボスの後から）。対象の戦闘数は `SINGLE_TILE_STAGES` で変えられます。

妖精は **1枠につき各戦闘1回、使用1 AP**。選択や配置先の確認では消費しません。同じ妖精を複数所持した場合も、枠ごとに使用回数を管理します。

砲撃や花火の爆発が別の大砲に届くと、その大砲も誘爆して発射します。

設置系の妖精（壁精霊・槍砲精霊・風見砲の妖精・花火妖精・隠密妖精）は、壁精霊と同じく置いたターンを含めて3ターンで消えます（マスの右下に残りターン数を表示）。

向きのある妖精（槍砲精霊・風見砲の妖精）は、向きごとの絵を使えます。`assets/sprites/spirits/<妖精ID>_directions.png` に、正方形を2×2に4分割した画像を置いてください（左上＝上向き、右上＝右向き、左下＝下向き、右下＝左向き。背景は透明）。ファイルがあれば盤上の大砲と配置中のプレビューがその向きの絵になり、無ければ通常のアイコンに向きの矢印を重ねて表示します。手札・報酬カード・説明パネルには通常のアイコン（`<妖精ID>.png`）を使います。槍砲精霊と風見砲の妖精のアイコンは、向き別の絵の右向き（右上）を切り出したものです。壁精霊・槍砲精霊・風見砲の妖精・花火妖精・斬撃精霊は本番の絵、飛刃精霊は斬撃精霊の絵を色替えした仮の絵です（`assets/sprites/spirits/` の同名ファイルを差し替えれば反映されます）。影縫い精霊は、入れ替え済みのターンは `shadow_stitch_spent.png`（糸がたるみ目が消えた絵）で表示します。一匹狼の妖精は盤面で `lone_wolf_directions.png`（上・右・下・左の4コマ横並び）を向きに合わせて使い、すねている間は `lone_wolf_sulk.png` を主人公に背を向ける向きに左右反転して表示します。各妖精には、配置・発動時の小さなエフェクトがあり、花火の爆発だけは派手に描きます。

どんぐり妖精の移動と攻撃はそれぞれ1 AP。召喚直後に自動で攻撃するのではなく、プレイヤーのターン終了を待ちます。配置した妖精・召喚した味方・地雷は次の戦闘へ持ち越しません。

初期妖精の候補と報酬候補は `scripts/run/run_model.gd` の `starting_fairy_pool` / `reward_fairy_pool` で分けています。初期候補はプールから重複なく3種類を抽選します。現在の初期プールは3種類なので全種類が並びます。追加時は `items/` の定義、`battle_model.gd` の `ITEMS`、抽選プールに登録してください。

## ステージの編集

`scenes/formations/run_01.tscn`〜`run_03.tscn` をGodotの **2Dエディター** で開きます。

1. 敵マーカーをドラッグします。マウスを離すと64px間隔のマス中央に揃います。
2. マーカーの複製・削除で数を変更します。
3. Inspectorの `enemy_kind` で種類を選びます。`Recruit` はHP1/AP1の歩兵、`Infantry` は従来のHP1/AP2の歩兵です。
4. ルートの `board_size` で盤面サイズ、`player_start` で開始位置を設定します。開始位置は水色の枠です。
5. 保存し、F5で初期ビルド選択から実行します。

同じマスに複数の敵を重ねず、水色のプレイヤー開始位置は空けてください。配置シーン単体は戦闘画面ではありません。

| 戦闘 | 盤面 | 初期配置 |
| --- | --- | --- |
| 1 | 4×4 | 右側にHP1/AP1の歩兵4体 |
| 2 | 5×5 | 右側中央の2×2にHP1/AP1の歩兵2体・重装兵2体を交互に配置 |
| 3 | 6×6 | 旧ステージ2を時計回りに90度回した配置。従来の歩兵4体・重装兵2体・地雷兵1体 |

HP1/AP1の歩兵と重装兵は到達可能な経路で接近し、隣接すると攻撃します。従来のAP2歩兵は包囲・突撃のAIを維持しています。地雷兵は移動後に地雷を設置します。地雷は地雷兵以外の敵・味方に1ダメージを与えます。

旧 `encounter_*.tscn` は以前の配置資料として残してあり、現在の進行では読み込みません。

## Windowsへの書き出し

Godotのエクスポートテンプレートをインストールし、「プロジェクト → エクスポート」で既存の **Windows Desktop** プリセットを使います。出力先は `build/windows/ALAKAZAR.exe`、x86_64・ゲームデータ埋め込み設定です。


書き出した実行ファイルとGodotのキャッシュはGit管理対象外です。このリポジトリには開発用プロジェクトと素材を収録しています。

### BGM

`assets/audio/bgm/` のBGMは `tools/generate_bgm.py` で生成しています。全曲で同じ音色とキー（Dマイナー）を使い、サイバー風のサウンドトラックとして統一しています。音色は、フィルターを通したノコギリ波ベース、デチューンしたパッド、エコー付きのアルペジオ、控えめなリードです。キックに合わせて全体がうねる（サイドチェイン）ようにし、どの音も高域を抑えてゲームの邪魔をしない音量にしています。音の合成はPython標準ライブラリだけで行い、同じ内容なら毎回同じ音になります。書き出しは軽量なOgg Vorbis（モノラル・32kHz・約74kbps）で、戦闘BGMでも約600KBです。エンコードには `pip install soundfile` が必要です。

| ファイル | 内容 |
| --- | --- |
| `battle_loop.ogg` | 戦闘BGM（132BPM・36小節、約65秒のループ）。大半は控えめなグルーヴで、1周に1回だけ盛り上げ→フック→クライマックス（ツインリードとスタブ）→余韻と山を作り、キックの抜けたブレイクを経て元に戻る |
| `draft_loop.ogg` | 出発前（武器・妖精の選択、報酬、結果画面）のBGM。ケルト×サイバー：Eドリアンの6/8ジグをティンホイッスル風の笛で、バグパイプ風のドローンとボウロン風の太鼓に乗せ、サイバーのアルペジオと後半の軽いキックを重ねる（約43秒のループ） |
| `camp_loop.ogg` | キャンプのBGM。Dミクソリディアン・3拍子のスローエア。ハープ風のアルペジオ、笛、ドローン、控えめな焚き火の音、かすかなデータの雨（約38秒のループ）。この2曲はノイズを抑え、高めの音質で書き出し |
| `boss_loop.ogg` | 最初のボス戦のBGM（Eマイナー・140BPM・32小節、約55秒のループ）。重い行進曲調で、Eの上にFを当てた不穏な進行、オクターブで跳ねるベース、行進のフック、ツインリードのクライマックス、キックの抜けたブレイク |
| `rotorick_loop.ogg` | ロトリック戦のBGM（Aハーモニックマイナー・152BPMの3連符、約44秒のループ）。1小節目からメロディ全開で、ループ中ずっと賑やかな狂ったサイバーサーカス調（ブンチャッチャのベース、半音で転がるリード、リールが回るような速いアルペジオ）。途中の「執行」パートも勢いを保ったまま鐘と低い旋律で不穏にし、大当たりの鐘の上昇音からクライマックスへ |
| `rotorick_error.ogg` / `rotorick_jackpot.ogg` | ロトリック曲の出目5版（こもった音・ピッチの揺れ・ビットクラッシュ・途切れる、故障した機械の音。キックとメロディが抜ける）と出目7版（毎拍の金の鐘、1オクターブ上のメロディ、重いキックと低音）。通常版と1サンプル単位で同じ長さ・同じ拍で、ゲームでは3つを同時に再生し、表示中の出目に合わせて0.5秒で音量を切り替える（`AudioStreamSynchronized`）ので、曲の途中でも同じ拍のまま継ぎ目なく変わる |
| `victory.ogg` | 勝利ジングル（上昇アルペジオからDメジャーで解決） |
| `defeat.ogg` | 敗北ジングル（戦闘のパッドがテープストップして沈む） |

曲を変更する場合は、スクリプト内の構成と各セクションの音量（`SECTIONS`）、コード進行（`CHORDS`）、フック（`HOOK`）を編集してから次のコマンドで再生成します。

```sh
python3 tools/generate_bgm.py
python3 tools/generate_bgm.py draft_loop.ogg camp_loop.ogg  # 指定した曲だけ
```

戦闘BGMはループ前提で循環的に書き出しており、終端のエコーやパッドの余韻が先頭につながります。Vorbisはサンプル数をそのまま保つため、インポート設定（`battle_loop.ogg.import` の `loop=true`）で継ぎ目なくループ再生されます。再生成してもこの設定はそのまま使われます。
